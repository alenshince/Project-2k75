### Project Description
[Project 2K75 is an interactive, browser-based sci-fi simulation built with React, TypeScript, Vite, and Three.js. It places the operator inside an exoplanetary survey terminal charting 75 procedurally generated celestial bodies paired with real-time Web Audio synthesis and narrative lore from Malayalam cinema icons Dasan and Vijayan.]

### The Problem (that doesn't exist)
[While trying to plot a direct hyperspace transit route to the Dubai quadrant, two intrepid travelers—Dasan and Vijayan—made a critical navigational error and jumped blindly into an uncharted sector of deep space[cite: 1]. Instead of asking for directions or making a simple U-turn, they decided the only rational solution was to survey, catalog, and analyze every single celestial body in the sector until one looked vaguely familiar[cite: 1].]

### The Solution (that nobody asked for)
[Project 2K75: An autonomous deep-space survey rig powered by Three.js and the Malluvaly AI terminal[cite: 1]. The system forces the operator to run multi-spectrum scans across 75 random alien planets accompanied by procedurally synthesized soundscapes, only to trigger an unrecoverable system glitch storm, audio failure, and kernel panic upon arriving at Planet #75 (The Doomsnexus Anomaly)[cite: 1].]

*Project 2K75 is an interactive, browser-based sci-fi simulation built with React, TypeScript, Vite, and Three.js (@react-three/fiber and @react-three/drei). The application puts the operator in control of an exoplanetary survey terminal charting 75 procedurally rendered celestial bodies in deep space.  Framed by the comedic narrative lore of legendary interstellar wanderers Dasan and Vijayan—who became stranded in an uncharted star sector after miscalculating a hyper-lane jump en route to the Dubai quadrant—the simulation couples real-time procedural frequency modulation via the native Web Audio API with interactive multi-spectrum planetary scanning mechanics.  As operators navigate through the 75-world catalog via the Malluvaly AI terminal interface, the journey culminates at Planet #75 (the Doomsnexus Anomaly), triggering an orchestrated failure sequence featuring custom canvas chromatic aberration shaders, audio distortion, simulated kernel panic logs, and seamless cutscene transitions.*
